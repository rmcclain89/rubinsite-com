# Rubin McClain website

Static website preview. Deploy on Netlify with publish directory `dist` and no build command.

Edit HTML, CSS and JavaScript directly in dist. Website images live in dist/assets. No Codespace or build tool is required.

The inquiry form uses Netlify Forms. Netlify scans the published HTML in `dist` for the form definition, and the JavaScript submits URL-encoded form data and displays the submission result.

Before launch: replace photo/book placeholders, test desktop and mobile layouts, and remove noindex metadata and the preview badge when approved. Do not connect the final domain before these checks.
