# Rubin McClain website

Static website preview. Deploy on Netlify with publish directory `dist` and no build command.

Edit HTML, CSS and JavaScript directly in dist. Website images live in dist/assets. No Codespace or build tool is required.

Before launch: replace photo/book placeholders, connect the demo contact form to a real submission service, test desktop and mobile layouts, and remove noindex metadata and the preview badge when approved. Do not connect the final domain before these checks.
